# 🧮 関数探究アプリ — Function Explorer

小学校高学年から大学まで、関数を「見る・動かす・予想する・比べる・説明する」ための探究学習アプリです。

**インストール不要・ブラウザだけで利用できます。**

## このアプリで大切にしていること

1. 予想する
2. 1つだけ変えてみる
3. グラフ・表・式を比べる
4. 自分の言葉で説明する

答えを先に教えるのではなく、「なぜそうなるのか」を自分で発見することを大切にしています。

## 主な機能

- 関数グラフ・数値表・式の連動
- パラメータを動かす探究
- 学習段階別の問い
- 探究ノート・実験記録
- 学習ナビ
- 自分で探究をつくる
- 自分で問題をつくる
- 探究レポート
- 授業用探究カード
- 授業ライブラリ
- 学びのポートフォリオ
- 3つの学習ルート
- 印刷・記録の書き出し

## 学習段階

### 小学校
比例・反比例などを中心に、「どこが変わったか」「何が同じか」を目で確かめます。

### 中学校
一次関数・二次関数などで、変化の割合、傾き、切片、グラフの特徴を表・式・グラフから探究します。

### 高等学校
二次関数、三角関数、指数・対数関数などで、パラメータとグラフの関係や変換を探究します。

### 大学
定義・仮定・極限・微分・積分などと関数を結び付けて考える入口として利用できます。

## 先生へ

先生が問いを設定し、学習者の考えを見取り、必要な場面で支援する使い方を想定しています。

**導入 → 予想 → 個人探究 → 比較・交流 → 全体共有 → まとめ**

詳しくは `MANUAL.md`、子ども向けには `CHILD_GUIDE.md` をご覧ください。

## プライバシー

学習記録は基本的に利用中のブラウザ内への保存を前提としています。氏名などの個人情報を入力しない運用を推奨します。学校での利用では学校・自治体の情報セキュリティ方針に従ってください。

## 技術仕様

- 基本構成：単一 `index.html`
- CSS / JavaScript：HTML内に内蔵
- 外部サーバーへの学習記録送信を前提としない設計
- PC・タブレット・電子黒板を想定
