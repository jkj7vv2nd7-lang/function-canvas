# 🧮 数学探究キャンバス (Math Inquiry Canvas)

小学校・中学校・高校の関数学習に対応した、直感的で双方向な「デジタル学習黒板＆探究アプリ」です。  
インストール不要・ブラウザだけで動くため、GIGAスクール構想の1人1台端末（Chromebook、iPad、PC等）や大型提示装置（電子黒板）でそのまま活用いただけます。

---

## 📸 アプリの特長
- 🎒 **小・中・高の学習指導要領に対応**（比例・反比例、一次関数、2乗に比例する関数、二次関数一般形、三角関数、指数・対数関数）
- 📊 **「数値の変化（表）」と「グラフ（Canvas）」の双方向連動**
- ✍️ **作図機能**（点を打つ、直線で結ぶ、複数点をなめらかに結ぶフリーハンド風曲線）
- 💡 **「自力探究 ＆ 答え合わせ」機能**（正解グラフの表示/非表示、手入力y値と正解との誤差フィードバック、変化の割合ガイド）
- ⌨️ **全角自動変換**（子どもが全角で数字や「-」を入力しても、自動で半角数値に補正して計算）

---

## 📱 操作方法（基本ガイド）

### 1. 共通ヘッダー（画面最上部）
* **学年タブ切り替え**: `🎒 小学校` / `🏫 中学校` / `🎓 高校` を選ぶと、その学年に合った関数と初期設定に切り替わります。
* **🔍- / 🔍+**: 座標平面の目盛り幅（ズーム）を調整します。
* **📺 授業提示**: 文字やボタンが大きくなり、大型提示装置や電子黒板で見やすくなります。
* **⛶ 画面いっぱい**: フルスクリーン表示に切り替えます。
* **📸 画像保存**: 現在のキャンバス描画状態をPNG画像としてダウンロードします（振り返りシート用）。

---

### 2. 左側操作パネル
* **💡 自力探究 ＆ 答え合わせ**:
  * **「式のグラフを表示」**: 実際の計算式に基づいた正解のグラフ（青線）を表示/非表示します。
  * **「表の正解情報を表示」**: 表のy行に正解の計算結果を一括表示します。
  * **「変化の割合ガイドを表示」**: プロットされた点と点の間に、$\Delta x$（xの増加量）と $\Delta y$（yの増加量）を示す直角三角形と数値を自動描画します。
* **関数の種類を選ぶ**: 学年に応じた関数をワンタップで切り替えます。
* **① 式のパラメータ調整**: スライダーを動かすことで、変化の割合（$a$）や切片（$b$）、頂点の位置（$p, q$）によるグラフの変化をリアルタイムに確認できます。
* **② 2直線の交点表示**（中学・一次関数等）: 2本目の直線を出して、連立方程式の解（交点座標）を可視化します。

---

### 3. フローティング「表（パネル）」
* **ドラッグ移動**: 上部の黒いヘッダーを掴んで、画面の好きな場所へ動かせます。
* **xの刻み幅プリセット**: `7組` `9組` `0.5刻み` `正の数` などを押すと、一括で表のx軸の変域を変更できます。
* **xの値の自由変更**: 表の $x$ のセルは自由に書き換え可能です。
* **yの手入力**: 子どもたちが計算した予測値を入力できます。正解グラフ非表示時には、プロットした点に `[正解!]` や `[差: 0.5]` などのヒント・誤差フィードバックが出ます。

---

### 4. 下部作図ツールバー
* **🖐 移動**: 打った点をドラッグして移動させます。
* **● 点を置く**: キャンバス上の好きな位置（マス目や交点）をタップしてプロットします。
* **／ 直線で結ぶ**: 点を2つ順にタップすると、その2点を通る直線を描画します。
* **~ 複数点を結ぶ曲線**: 反比例や2乗に比例する関数などで、いくつかの点を順にタップして「✓ 結び終える」を押すと、点と点をなめらかにつなぐスプライン曲線を描画します。
* **🗑 作図リセット**: 自分が描いた点や線をすべて消去します。

## 🏫 授業での活用例（指導案のアイディア）

### 例1：【中学校2年】一次関数の「変化の割合」の本質に気づく探究（1時間）
1. **課題提示**: アプリで $y = 2x + 1$ の式だけを見せ、正解グラフ・正解表は隠しておきます。
2. **予想・表の入力**: 児童生徒は表の $y$ の欄に自分で計算した値を入力し、キャンバスに点をプロットします。
3. **探究（作図）**: 「／ 直線で結ぶ」ツールで点を結びます。
4. **視覚的気づき**: **「📐 変化の割合ガイドを表示」** をオンにします。$x$ が $1$ 増えるごとに $y$ が $2$ ずつ増える直角三角形（$\Delta x=1, \Delta y=2$）が視覚化され、「変化の割合＝傾き」の意味を直感的に理解できます。
5. **答え合わせ**: **「👁️ 式のグラフを表示」** をオンにして、自分の引いた直線とピッタリ重なるか確認します。

---

### 例2：【中学校3年】$y = ax^2$ のグラフの特徴（放物線）を描く（1時間）
1. **課題提示**: $y = x^2$ の表で、$x = -3, -2, -1, 0, 1, 2, 3$ のときの $y$ の値を求めさせます。
2. **プロット**: 計算した座標に「● 点を置く」で点を打たせます。
3. **曲線の描画**: 直線では結べないことに気づかせ、「~ 複数点を結ぶ曲線」を使って点を順番にタップし、滑らかな曲線（放物線）を作成させます。
4. **比較・深まり**: パラメータ $a$ のスライダー（$1 \rightarrow 2 \rightarrow 0.5 \rightarrow -1$）を動かし、グラフの開き具合や上下の向きがどう変化するかを実験・観察させます。

---

### 例3：【小学校6年】比例・反比例の比較と性質の発見
1. **比較**: 画面左上で「比例」と「反比例」を切り替えながら、表の $x$ と $y$ の積（$x \times y = a$）や商（$y / x = a$）の関係性を観察させます。
2. **象限の配慮**: 小学校モードでは第一象限（$x \ge 0, y \ge 0$）のみが大きく表示されるため、混乱なく学習に集中できます。
